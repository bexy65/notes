Basic note app: 

To start: the server (backend) - npm run dev
To start: the client (frontend) - npm run dev

###
    CRUD Operations and search operation on Notes.
    Register functionality.
    Account settings feature.
    Basic landing page where gets data from DB depending users and notes created.

    Libraries: 
    ReactQuill - Rich text editor for better note taking.
    bcrypt - for crypting password data.
    jsonwebtoken - for auth.

    CDN's:
    Boostrap 5 - for basic prebuild UI
    DOM Purify - for better protection and showing HTML on the website.

    Recap: 
    Basic note app where has auth, crud operations for notes, login/register functionality, every user stores notes, search feature to search notes with keyword(client-side).
